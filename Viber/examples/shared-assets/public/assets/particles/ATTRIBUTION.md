# Particle sprites

Source: [Kenney Particle Pack](https://kenney.nl/assets/particle-pack) (CC0 / public domain).

Original filenames kept alongside semantic aliases (`fire.png`, `smoke.png`, …) used by the VibeGame particle presets.

Kenney ships white-on-black sprites without an alpha channel. Files here were
converted to white RGB + luminance-as-alpha so NormalBlending billboards do not
show black squares.

See `LICENSE.txt` for the Kenney license text.
